# DocFinder
Document finder app


## Pornire rapidă

Acceseaza folderul DocFinder_Pachet_Windows

Dublu clic pe `Porneste-DocFinder.bat` (sau pe `Executabile\DocFinder-Windows-x64\DocFinder.exe`). La prima pornire, Windows SmartScreen poate afișa „Windows protected your PC”, deoarece executabilul nu este semnat digital. Alegeți *More info → Run anyway*
